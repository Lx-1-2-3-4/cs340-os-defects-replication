# Patch Size vs. Modification Locality (501–1000 Line Control Study)

**What we test.** The paper excludes patches above 500 changed lines as "large refactoring" and argues that OS bug fixes are small and modularly localized. We test whether smaller patches actually touch fewer logical modules—not just fewer files—and whether the localization conclusion still holds when real 501–1000 line defect fixes are included.

**How we set up the comparison.** Using non-overlapping size buckets (`1-9`, `10-29`, `30-49`, `50-99`, `100-500`, `501-1000`) and both raw-diff and production-only line counts, we combine: (1) all 1,500 baseline records, (2) 52 sampled baseline diffs, (3) 25 audited 501–1000 line patches from `systemd`, OpenHarmony, and AOSP, and (4) teammate Wu Yanyang's 9 file-mapped `systemd` fixes (`<=500` lines). Every file path is mapped to a logical subsystem/module via explicit directory rules (`map_path_to_module`) rather than equating file count with module count.

**What we observe.** First, 18 of 25 (72.0%) 501–1000 line candidates are excluded as test-only changes, feature additions, bulk cleanups, or merges, while 7 (28.0%) are genuine defect fixes—and 2 of those 7 drop below 500 lines in production code once test/doc lines are separated (e.g., OpenHarmony `security_huks#1497`: 638 raw lines vs. 19 production lines in 1 file). Second, across all `<=500` line buckets (`1-9` through `100-500`), median production modules touched stays at **1.0** (cross-module rate 0.0%–18.8%), whereas in `501-1000` (`n=7`) median modules jumps to **3.0** and cross-module rate reaches **71.4%** (and **75.0%** vs. **16.7%** within `systemd` alone).

**What this means for the paper's conclusions.** Separating files from logical modules *strengthens* the paper's modularization claim below 500 lines, because multi-file fixes still stay largely within one subsystem. However, the 500-line ceiling is a noisy proxy: it mixes test/doc inflation with code complexity and filters out real, predominantly cross-module fixes (71.4%) that require coordinated multi-module repair.
